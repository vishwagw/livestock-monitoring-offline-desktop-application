What happens to a flight

From flight log to headcount in five steps

  1. Ingest

    Reads DJI .SRT or telemetry CSV, plus boxes from YOLO, COCO, CSV or JSON. Each box is matched to its image by file name, frame number or timestamp.

  2. Georeference

    Casts a ray through every box using altitude, gimbal pitch and roll, heading and the lens FOV, and lands it on the ground in local UTM coordinates.

  3. Align

    Corrects each image's GPS and compass drift against its overlapping neighbours. In packed yards, images are pre-aligned before any clustering.

  4. Cluster

    DBSCAN with a 2 m body envelope, tightened automatically in dense groups. Two boxes in the same image are never merged into one animal.

  5. Deliver

    One point per animal with class and confidence, as CSV, GeoJSON and a map report. An audit trail links every merged detection back to its image.

Fits your existing workflow

Works with the files you already produce

Inputs

  • DJI .SRT video logs (Mavic 3, Air, Mini, Phantom 4, Mavic Pro styles)
  • Per-photo telemetry or flight-log CSVs (e.g. AirData), with units in feet or ms handled automatically
  • Detector output: YOLO .txt, COCO JSON, CSV or JSON boxes, pixel or normalised
  • Several flights at once, plus video frames or still photos

Deliverables

  • Headcount per class, with a confidence and a class-conflict flag per animal
  • CSV and GeoJSON points for the client's GIS
  • Per-detection audit: raw position, corrected position, assigned animal
  • validate command to score results against a gate or yard count

Speed

  • 55,000 detections in 4.7 s
  • 110,000 detections in 10.3 s
  • 221,000 detections in 21 s: linear scaling, full raw-log path
  • Live progress by stage, with an estimate of time remaining

Offline and deployable

  • Installers for Windows, macOS and Linux, with the engine bundled: no Python or internet needed
  • No data leaves the laptop; network access is blocked by design
  • Offline basemap from a local tile cache
  • CLI, Python API and JSON Schemas for automated pipelines
